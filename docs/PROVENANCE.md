# Release provenance

This release preserves the staged implementation used for the conservative IMV
amendment. It is a new code-only repository, not a copy of the research workspace
or its revision history. Dated directories identify analytical stages.

## Public-release changes

- Copy only enumerated source files, feature names, model configuration and protocol
  documents; exclude all patient inputs, statistical outputs and fitted objects.
- Read database user and connection settings from local environment variables;
  authentication stays outside the repository.
- Bundle the previously retained public upstream SQL with MIT notices. Missing
  snapshots now fail explicitly instead of downloading a changing branch.
- Remove two example ICU-stay identifier literals from upstream SQL comments;
  retain the methodological explanation and original license.
- Correct floating-point endpoint selection in the 5%-15% decision-curve viewport.
  This changes plotting bounds, not labels, fitted models or numerical estimates.
- Replace a stale local figure-generation comment with an accurate scope note.
  Preserve scientific limitations, protocol history and third-party attribution.
- Normalize text files to UTF-8/LF for portable Git checkouts.

The publication figures were not regenerated by this code release. The plotting
correction must be applied to the manuscript package separately before submission.

AI-assisted tools (including Codex) were used during code development, debugging,
review and preparation of release materials. This repository makes no claim of
exclusively human-written code. The manuscript's disclosure is not removed or
reduced by preparing this repository. Research authors remain responsible for
scientific review, lawful data access and interpretation.

Validation for this release is limited to source/manifest checks, syntax parsing
and data-free tests. It is not a new full rerun, a clinical adjudication, or an
independent replication of the study. Source hashes and a file allowlist are in
`PUBLIC_FILES.json`.
